# Bot Core

Main Discord bot application.

## Features

- Manga downloading
- Image cleaning
- Admin panel
- Download tracking

## Cogs

- `admin.py` - Admin commands
- `downloads.py` - Download management
- `general.py` - General commands
- `manga_cleaner.py` - Image processing
- `manga_translator.py` - Translation
- `search.py` - Search functionality
- `tracker_v3.py` - Progress tracking
